# @kbn/screenshotting-server

Stateless code pertaining to the capture of screenshots for Kibana Reporting.

> **POC note:** this package carries the config-gated `xpack.screenshotting.service.*` seam (see
> `src/config/schema.ts`) used by the multi-tenant reporting service proof of concept. The design
> writeup for that POC lives with the example plugin in
> [`x-pack/examples/reporting_service_poc/docs`](../../../../../x-pack/examples/reporting_service_poc/docs).
